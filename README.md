\# AI 客户邮件智能助手



一个基于 Python 和大语言模型 API 的客户邮件分析工具。通过 AI 自动识别客户邮件中的问题类型、核心需求，并生成建议处理方式，帮助提高客服邮件处理效率。



\## 一、项目功能



\- \*\*邮件分类\*\*：识别物流问题、商品咨询、退换货、商务订单、客户投诉等类型。

\- \*\*需求提取\*\*：提取客户邮件中的核心需求。

\- \*\*处理建议\*\*：根据邮件内容生成建议处理方式。

\- \*\*人工介入判断\*\*：根据预设业务规则判断是否需要人工介入。

\- \*\*批量分析\*\*：导入 TXT 文件，对多封邮件进行分析。

\- \*\*结果展示\*\*：通过桌面 GUI 界面查看分析结果和邮件详情。

\- \*\*CSV 导出\*\*：将分析结果导出为 CSV 文件。

\- \*\*异常处理\*\*：针对部分 API 连接异常、超时和服务端错误进行重试。

\- \*\*失败邮件重试\*\*：支持对分析失败的邮件单独重新分析。



\## 二、技术栈



| 技术 | 用途 |

|---|---|

| Python | 核心开发语言 |

| Tkinter | 桌面图形界面 |

| OpenAI Python SDK | 调用兼容 OpenAI 接口的 AI 服务 |

| CSV | 分析结果导出 |

| PyInstaller | 打包 Windows 可执行程序 |



\## 三、运行方式



\### 方式一：直接运行发布版



1\. 打开 `release/AI客户邮件智能助手` 文件夹。

2\. 双击 `AI客户邮件智能助手.exe`。

3\. 在软件中输入自己的 Agnes API Key。

4\. 点击「测试连接」。

5\. 导入客户邮件 TXT 文件。

6\. 点击「开始分析」。

7\. 分析完成后查看结果，并可导出 CSV。



\### 方式二：运行 Python 源代码



需要安装 Python，并安装依赖：



```bash

pip install openai

```



进入 `source` 文件夹后运行：



```bash

python mail\_assistant\_gui.py

```



\## 四、输入文件格式



使用 TXT 文件，每行一封邮件。



示例：



```text

我买的耳机怎么还没送到？

你们这款电脑支持外接两个显示器吗？

收到的商品外壳有划痕，我要求退货退款。

```



\## 五、人工介入判断规则



当前演示版本采用以下规则：



| 邮件分类 | 是否需要人工介入 |

|---|---|

| 客户投诉 | 是 |

| 退换货 | 是 |

| 商务订单 | 是 |

| 物流问题 | 否 |

| 商品咨询 | 否 |

| 其他/无法识别 | 待确认 |



以上规则属于演示业务规则，不代表所有企业的实际客服政策。



\## 六、API Key 安全说明



\- API Key 由使用者自行填写。

\- 软件默认隐藏 API Key。

\- API Key 仅在软件运行期间保存在内存中。

\- 关闭软件后不会持久化保存 API Key。

\- 不要将个人 API Key 上传至 GitHub，也不要将其写入源代码或打包程序。

\## 九、当前项目局限



这是一个本地运行的 AI 邮件分析工具，目前仍有以下限制：



1\. 尚未连接真实邮箱，邮件需要通过 TXT 文件导入。

2\. 尚未连接企业订单、物流或客户管理系统。

3\. AI 生成的处理建议需要人工核实，不能直接视为企业正式处理结果。

4\. 人工介入规则目前为固定演示规则，尚未提供可视化配置。

5\. 每封邮件需要单独调用一次 AI API，实际使用会产生相应 API 消耗。
